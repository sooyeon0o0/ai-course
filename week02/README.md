<h2>어텐션 프로그래밍이란?</h2>

어텐션은 사람이 긴 글을 읽을 때처럼 중요 내용에 집중하게 만드는 기술입니다.

질문이 들어오면 마치 검색창에 키워드를 치듯 관련된 단어 제목(Key)들을 찾아냅니다.

그중 어떤 단어가 중요한지 연관성을 따져 0에서 100% 사이의 중요도 점수를 매깁니다.

모든 단어를 다 똑같이 기억하는 대신, 계산된 점수가 높은 핵심 단어의 뜻(Value)에 더 주의를 기울입니다.

이를 통해 문장이 아무리 길어지거나 순서가 바뀌어도 뜻이 통하는 정확한 결과를 만들어냅니다.
