# 주차 요금 계산기 스펙

## 1. 프로그램 개요

입차 시각과 출차 시각을 받아 주차 시간과 요금을 계산한다. 계산 결과를 오늘의 주차 기록 목록에 누적하고, 기록별 삭제와 오늘 받은 요금의 총합을 제공하는 단일 창 프로그램이다.

파일은 다음과 같이 역할을 분리한다.

- `calculator.py`: 시간·요금 계산과 기록 관리만 담당하며 화면 코드를 포함하지 않는다.
- `test_calculator.py`: 계산 로직을 검증하고 실행 결과에 통과 및 실패 수를 출력한다.
- `main.py`: Tkinter 화면과 사용자 입력 처리를 담당한다.
- `spec.md`: 동작 규칙과 테스트 표를 기록한다.

## 2. 동작 규칙

### 2.1 시간 입력

- 시간은 24시간제 `HH:MM`으로 계산 파일에 전달한다.
- 화면의 수기 입력란에서는 숫자만 입력해도 두 자리 뒤에 `:`를 자동 삽입한다. 예: `0930` → `09:30`.
- 사용자는 수기 입력과 드롭다운 입력 중 하나를 선택할 수 있다.
- 드롭다운은 시(00~23)와 분(00~59)을 각각 선택한다.
- 숫자로 이루어진 시·분이 정상 범위를 넘으면 자동으로 유효한 시각으로 보정한다.
  - `25:00` → `01:00`
  - `09:65` → `10:05`
- 숫자가 아니거나 `HH:MM` 구조가 아니면 계산하지 않고 오류를 표시한다.
- 입차 또는 출차 입력이 비어 있으면 `모든 시간을 입력해주세요` 경고를 표시한다.

### 2.2 주차 시간

- 보정된 출차 시각이 입차 시각보다 늦으면 두 시각의 차이를 사용한다.
- 보정된 출차 시각이 입차 시각보다 빠르거나 같으면 다음 날 출차로 간주한다.
  - 입차 `23:00`, 출차 `01:00` → 2시간
  - 입차 `10:00`, 출차 `10:00` → 24시간

### 2.3 요금

- 최초 30분까지 무료이다.
- 30분을 초과한 시간은 10분마다 500원이다.
- 10분 미만의 나머지는 10분 1회로 올림한다.
- 한 기록의 일일 최대 요금은 20,000원이다.
- 화면의 모든 금액에는 천 단위 쉼표와 `원`을 붙인다.

### 2.4 기록과 삭제

- 계산할 때마다 입차, 출차, 주차 시간, 요금을 목록에 추가한다.
- 각 행에는 해당 행 전용 삭제 버튼을 둔다.
- 삭제하면 그 항목만 사라지고 오늘의 총합에서 해당 요금을 즉시 제외한다.
