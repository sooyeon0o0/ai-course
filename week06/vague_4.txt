전화번호를 어떤 형식으로 정리하고 싶은지에 따라 여러 가지 방법이 있습니다. 가장 흔히 쓰이는 세 가지 패턴(하이픈 추가, 숫자만 추출, 특정 형식으로 통일)에 맞춰 Python 코드를 작성해 드립니다.

### 1. 파이썬 코드 예시

```python
import re

def format_phone_number(phone):
    """
    입력된 문자열에서 숫자만 추출한 뒤, 
    표준 하이픈 형식(010-xxxx-xxxx)으로 변환합니다.
    """
    # 1. 숫자만 남기고 모든 문자 제거
    digits = re.sub(r'\D', '', phone)
    
    # 2. 길이에 따른 포맷팅
    length = len(digits)
    
    if length == 11:
        # 010-1234-5678 형식
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    elif length == 10:
        # 02-123-4567 또는 010-123-4567 형식
        # 앞의 3자리가 02인 경우(서울 지역번호)와 010인 경우를 고려하여 처리
        if digits.startswith('02'):
            return f"{digits[:2]}-{digits[2:5]}-{digits[5:]}"
        else:
            return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
    elif length < 10:
        # 번호가 너무 짧은 경우 그대로 반환하거나 에러 처리
        return digits
    else:
        # 그 외의 경우 (예: 국제전화 등) 숫자만 반환
        return digits

def clean_only_numbers(phone):
    """숫자만 추출하는 아주 간단한 함수"""
    return re.sub(r'\D', '', phone)

# --- 테스트 ---
test_numbers = [
    "01012345678",          # 숫자만 있는 경우
    "010-1234-5678",        # 이미 하이픈이 있는 경우
    "02.123.4567",          # 마침표가 있는 경우
    "010 1234 5678",        # 공백이 있는 경우
    "0101234567",           # 10자리 번호
    "(02)1234567",          # 괄호가 있는 경우
    "abc010-1234-5678def"  # 문자가 섞인 경우
]

print(f"{'원본':<20} | {'정리된 결과'}")
print("-" * 40)
for num in test_numbers:
    print(f"{num:<20} | {format_phone_number(num)}")
```

### 2. 코드 설명

1.  **`re.sub(r'\D', '', phone)`**: 정규 표현식(Regular Expression)을 사용합니다. `\D`는 "숫자가 아닌 모든 것"을 의미합니다. 즉, 전화번호에 포함된 하이픈(`-`), 공백(` `), 괄호(`()`), 마침표(`.`) 등을 모두 제거하고 **숫자만 남깁니다.**
2.  **조건문 (`if-elif`)**:
    *   **11자리**: `010-1234-5678` 처럼 3-4-4 구조로 만듭니다.
    *   **10자리**: 서울 지역번호(`02`)인 경우 `2-3-4` 구조로, 휴대폰 번호인 경우 `3-3-4` 구조로 유연하게 대응하도록 설계했습니다.
3.  **결과값**: 입력값이 어떤 형태이든 상관없이 깨끗하게 정리된 문자열을 반환합니다.

### 3. 활용 팁

*   **데이터베이스 저장용**: 만약 DB에 저장할 목적이라면 하이픈 없이 숫자만 저장하는 것이 검색 속도나 용량 면에서 유리합니다. 이때는 `clean_only_numbers` 함수를 사용하세요.
