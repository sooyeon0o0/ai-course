전화번호를 어떤 형식으로 정리하고 싶은지에 따라 여러 가지 방법이 있습니다. 가장 흔히 쓰이는 **1) 숫자만 추출하기**, **2) 하이픈(-)을 넣어 표준 형식으로 만들기**, **3) 특정 국가 번호 붙이기** 등의 기능을 포함한 파이썬 함수를 만들어 드릴게요.

### 파이썬을 이용한 전화번호 정리 함수

이 코드는 정규 표현식(`re` 모듈)을 사용하여 매우 강력하게 작동합니다.

```python
import re

def format_phone_number(phone_str):
    """
    전화번호를 입력받아 '010-0000-0000' 또는 '02-000-0000' 형식으로 정리합니다.
    """
    # 1. 숫자 이외의 모든 문자 제거
    digits = re.sub(r'\D', '', phone_str)
    
    # 숫자가 너무 적으면 그대로 반환하거나 에러 처리
    if len(digits) < 9:
        return "유효하지 않은 번호입니다."

    # 2. 번호 길이에 따른 포맷팅
    length = len(digits)
    
    # 휴대폰 번호 (010, 011 등 11자리 또는 10자리)
    if length == 11:
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    elif length == 10:
        # 010-1234-5678 형태인지, 02-123-4567 형태인지 구분 필요
        if digits.startswith('01'): # 휴대폰 10자리 (예: 010-123-4567)
            return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
        else: # 지역번호 2자리 (예: 02-123-4567)
            return f"{digits[:2]}-{digits[2:5]}-{digits[5:]}"
            
    # 지역번호 2자리 + 국번 4자리 + 번호 4자리 (예: 02-1234-5678) -> 12자리인 경우 드묾
    elif length == 12:
        return f"{digits[:2]}-{digits[2:6]}-{digits[6:]}"
        
    # 일반적인 9~10자리 (예: 02-123-4567 또는 031-123-4567)
    elif length == 9:
        return f"{digits[:2]}-{digits[2:5]}-{digits[5:]}"

    # 그 외의 경우 (그냥 숫자 사이에 하이픈을 넣기 어려우므로 원본 숫자만 반환하거나 예외처리)
    return digits

# --- 테스트 코드 ---
test_numbers = [
    "01012345678",          # 일반 휴대폰
    "010-1234-5678",        # 이미 하이픈 있음
    "021234567",            # 서울 지역번호 3자리 형태
    "031-123-4567",         # 경기 지역번호
    "010 1234 5678",        # 공백 포함
    "010.1234.5678",        # 마침표 포함
    "abc010-1234-5678def"   # 문자 포함
]

print(f"{'입력값':<20} | {'결과값'}")
print("-" * 35)
for num in test_numbers:
    print(f"{num:<20} | {format_phone_number(num)}")
```

### 함수 설명

1.  **`re.sub(r'\D', '', phone_str)`**:
    *   `\D`는 숫자가 아닌 모든 문자를 의미합니다.
    *   이 코드를 통해 입력된 문자열에서 하이픈(`-`), 공백(` `), 점(`.`), 문자 등을 모두 제거하고 **순수 숫자만 남깁니다.**
2.  **길이 기반 분기 (`if-elif`)**:
    *   한국 전화번호 체계에 맞춰 길이를 체크합니다.
    *   **11자리**: `010-XXXX-XXXX`
    *   **10자리**: `010-XXX-XXXX` 또는 `02-XXX-XXXX`로 구분하여 처리합니다.
    *   **9자리**: `02-XXX-XXXX` 또는 `031-XXX-XXXX` 형태로 처리합니다.
3.  **확장성**:
    *   만약 해외 전화번호를 정리해야 한다면 `+82`를 붙이는 로직을 추가할 수 있습니다.

### 실행 결과 예시
```text
입력값                 | 결과값
-----------------------------------
01012345678          | 010-1234-5678
010-1234-5678        | 010-1234-5678
021234567            | 02-123-4567
031-123-4567         | 031-123-4567
010 1234 5678        | 010-1234-5678
010.1234.5678        | 010-1234-5678
abc010-1234-5678def  | 010-1234-5678
```

**팁:** 만약 엑셀 파일(CSV)에 있는 수천 개의 전화번호를 한꺼번에 바꾸고 싶다면, 이 함수를 `pandas` 라이브러리의 `.apply()` 함수와 함께 사용하면 매우 빠르게 작업할 수 있습니다. 필요하시면 그 방법도 알려드릴게요!
