전화번호를 어떤 형식으로 정리하고 싶은지에 따라 여러 가지 방법이 있습니다. 가장 대표적인 세 가지 상황(하이픈 추가, 숫자만 추출, 특정 형식 통일)에 맞춰 파이썬(Python) 코드를 작성해 드립니다.

### 1. 숫자만 남기고 하이픈(`-`) 형식으로 통일하기
사용자가 `01012345678`, `010-1234-5678`, `010 1234 5678` 등 제각각으로 입력해도 모두 `010-1234-5678` 형태로 만드는 함수입니다.

```python
import re

def format_phone_number(phone_str):
    # 1. 숫자 이외의 모든 문자를 제거
    numbers = re.sub(r'[^0-9]', '', str(phone_str))
    
    # 2. 길이에 따라 하이픈 삽입
    length = len(numbers)
    
    if length == 11:  # 010-1234-5678 형식
        return f"{numbers[:3]}-{numbers[3:7]}-{numbers[7:]}"
    elif length == 10: # 02-123-4567 또는 010-123-4567 형식
        # 앞자리가 02인 경우와 01x인 경우를 구분할 수 있지만, 
        # 일반적인 휴대폰 번호 기준으로 처리
        return f"{numbers[:3]}-{numbers[3:6]}-{numbers[6:]}"
    elif length == 9:  # 02-1234-5678 형식 (지역번호가 2자리일 때)
        return f"{numbers[:2]}-{numbers[2:6]}-{numbers[6:]}"
    else:
        return numbers  # 형식이 맞지 않으면 숫자만 반환

# 테스트
test_numbers = ["01012345678", "010-1234-5678", "010 1234 5678", "021234567", "0101234567"]
for n in test_numbers:
    print(f"{n}  =>  {format_phone_number(n)}")
```

### 2. 데이터 정제용: 숫자만 추출하기 (Cleaning)
데이터베이스에 저장하거나 계산을 위해 특수문자를 모두 없애고 **숫자만** 남기고 싶을 때 사용합니다.

```python
import re

def clean_phone_number(phone_str):
    # 숫자만 남기고 모두 제거
    return re.sub(r'[^0-9]', '', str(phone_str))

# 테스트
print(clean_phone_number("010-1234-5678")) # 출력: 01012345678
print(clean_phone_number("(02) 123-4567")) # 출력: 021234567
```

### 3. 리스트 전체를 한꺼번에 정리하기 (Pandas 활용)
엑셀 파일이나 CSV 데이터를 다루고 있다면 `pandas` 라이브러리를 사용하는 것이 가장 효율적입니다.

```python
import pandas as pd
import re

def clean_phone_series(series):
    # 숫자가 아닌 것을 제거하는 함수 적용
    return series.astype(str).apply(lambda x: re.sub(r'[^0-9]', '', x))

# 예시 데이터 생성
data = {'name': ['Kim', 'Lee', 'Park'],
        'phone': ['010-1234-5678', '010.9876.5432', '(02)111-2222']}
df = pd.DataFrame(data)

# 함수 적용
df['phone_cleaned'] = clean_phone_series(df['phone'])

print(df)
```
