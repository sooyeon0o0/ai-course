전화번호를 어떤 형식으로 정리하고 싶으신가요? 보통 가장 많이 쓰이는 방식은 **"숫자만 남기기"** 또는 **"하이픈(`-`)을 넣어 표준 형식으로 만들기"**입니다.

Python을 사용한 세 가지 대표적인 케이스의 함수를 만들어 보았습니다.

---

### 1. 숫자만 추출하기 (가장 기본)
입력된 문자열에서 숫자 이외의 모든 문자(공백, 하이픈, 괄호 등)를 제거합니다. 데이터베이스에 저장할 때 가장 유용합니다.

```python
import re

def clean_phone_number(phone):
    # 숫자가 아닌 모든 문자를 빈 문자열('')로 대체
    return re.sub(r'[^0-9]', '', phone)

# 테스트
print(clean_phone_number("010-1234-5678"))    # 출력: 01012345678
print(clean_phone_number("(02) 123-4567"))  # 출력: 021234567
print(clean_phone_number("010.1234.5678"))  # 출력: 01012345678
```

---

### 2. 표준 하이픈(`-`) 형식으로 변환하기
숫자만 있는 상태이거나 지저분한 상태의 번호를 `010-1234-5678` 같은 형식으로 예쁘게 만들어줍니다.

```python
import re

def format_phone_number(phone):
    # 1. 먼저 숫자만 남깁니다.
    digits = re.sub(r'[^0-9]', '', phone)
    
    # 2. 길이에 따라 형식을 적용합니다.
    length = len(digits)
    
    if length == 8: # 서울 지역번호(02) 등 8자리 (예: 02123456)
        return f"{digits[:2]}-{digits[2:]}"
    elif length == 10: # 02-123-4567 또는 010-123-4567
        return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
    elif length == 11: # 010-1234-5678
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    else:
        return digits # 형식이 맞지 않으면 숫자만 반환

# 테스트
print(format_phone_number("01012345678"))     # 출력: 010-1234-5678
print(format_phone_number("021234567"))      # 출력: 02-1234-567
print(format_phone_number("010-123-4567"))    # 출력: 010-123-4567
print(format_phone_number("(02) 1234-5678")) # 출력: 02-1234-5678
```

### 3. [종합판] 데이터 정제용 함수 (추천)
실무에서는 입력값이 제각각이기 때문에, **"지저분한 입력을 받아서 -> 숫자로 만든 뒤 -> 표준 포맷으로 변환"**하는 과정이 한 번에 일어나는 것이 좋습니다.

```python
import re

def standardize_phone(phone):
    """
    지저분한 전화번호를 입력받아 표준 000-0000-0000 형식으로 반환합니다.
    """
    # 숫자만 추출
    digits = re.sub(r'[^0-9]', '', str(phone))
    
    # 예외 처리: 너무 짧거나 긴 경우
    if len(digits) < 8:
        return "Invalid Number"
    
    # 1. 휴대폰 번호 (010, 011 등 11자리)
    if len(digits) == 11:
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    
    # 2. 일반/지역번호 (10자리: 02-123-4567 또는 010-123-4567)
    elif len(digits) == 10:
        # 첫 두 자리가 02인 경우 (서울)
        if digits.startswith('02'):
            return f"{digits[:2]}-{digits[2:5]}-{digits[5:]}"
        else:
            return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
            
    # 3. 지역번호 포함 9자리 (예: 02-123-4567 형태의 옛날 번호 등)
    elif len(digits) == 9:
        if digits.startswith('02'):
            return f"{digits[:2]}-{digits[2:4]}-{digits[4:]}"
        else:
            return f"{digits[:3]}-{digits[3:5]}-{digits[5:]}"

    return digits # 그 외엔 숫자만 반환

# 테스트 케이스
test_list = [
    "01012345678",
    "010-1234-5678",
    "(02)123-4567",
    "02.1234.5678",
    "010 1234 5678",
    "031-123-4567",
    "123" # 잘못된 번호
]

for t in test_list:
    print(f"{t}  =>  {standardize_phone(t)}")
```
