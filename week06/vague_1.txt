전화번호를 어떤 형식으로 정리하고 싶은지에 따라 여러 가지 방법이 있습니다. 가장 흔히 쓰이는 **1) 하이픈(-) 제거**, **2) 표준 형식(010-xxxx-xxxx)으로 변환**, **3) 숫자만 추출**하는 세 가지 버전을 파이썬(Python) 코드로 작성해 드립니다.

### 파이썬 코드 구현

```python
import re

def clean_phone_number(phone):
    """
    전화번호를 정리하는 함수
    1. 숫자 이외의 모든 문자 제거
    2. 길이에 따라 적절한 포맷팅 적용
    """
    # 1. 숫자만 남기고 모두 제거 (정규표현식 사용)
    digits = re.sub(r'\D', '', phone)
    
    length = len(digits)
    
    # 2. 패턴에 따른 포맷팅
    # 휴대폰 번호 (예: 01012345678 -> 010-1234-5678)
    if length == 11 and digits.startswith('01'):
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    
    # 휴대폰 번호 (예: 0101235678 -> 010-123-5678)
    elif length == 10 and digits.startswith('01'):
        return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
    
    # 일반 지역번호/유선전화 (예: 021234567 -> 02-123-4567)
    elif 9 <= length <= 10:
        if digits.startswith('02'): # 서울 지역번호
            return f"{digits[:2]}-{digits[2:6]}-{digits[6:]}"
        else: # 기타 지역번호
            return f"{digits[:2]}-{digits[2:5]}-{digits[5:]}"
            
    # 그 외의 경우 (숫자만 반환하거나 그대로 반환)
    return digits

# --- 테스트 코드 ---
test_numbers = [
    "010-1234-5678",    # 이미 포맷팅 된 경우
    "01012345678",      # 숫자만 있는 경우
    "010.1234.5678",    # 점으로 구분된 경우
    "021234567",        # 서울 유선전화
    "0311234567",       # 경기도 유선전화
    "010-123-4567",     # 짧은 휴대폰 번호
    "(010) 1234 5678",  # 괄호와 공백이 있는 경우
    "abc-1234-defg"     # 문자가 섞인 경우
]

print(f"{'원본':<20} | {'정리된 결과':<15}")
print("-" * 40)
for num in test_numbers:
    print(f"{num:<20} | {clean_phone_number(num):<15}")
```

### 코드 설명

1.  **`re.sub(r'\D', '', phone)`**: 정규표현식을 사용하여 숫자가 아닌 모든 문자(`\D`)를 빈 문자열로 바꿉니다. 이 과정을 거치면 `(010) 1234-5678` 같은 복잡한 문자열도 `01012345678`로 깔끔하게 변합니다.
2.  **조건문 분기**:
    *   **11자리 (010...)**: 가장 일반적인 휴대폰 형태 (`xxx-xxxx-xxxx`)입니다.
    *   **10자리 (010...)**: 중간 자리가 3자리인 휴대폰 형태 (`xxx-xxx-xxxx`)입니다.
    *   **지역번호 처리**: 서울(`02`)은 앞 두 자리를 기준으로 나누고, 그 외 지역은 앞 두 자리를 기준으로 나누도록 설계했습니다.
3.  **유연성**: 입력값에 공백, 하이픈, 마침표, 괄호가 섞여 있어도 숫자만 뽑아내어 다시 예쁘게 만들어줍니다.
