스마트폰 불편함 해결 프로젝트 기획서
1. 프로젝트 개요
프로젝트명: 나중에 보기 (Later View)
프로젝트 주제: 저장한 링크를 잊어버리는 불편함 해결
개발 형태: 모바일 앱
AI 모델: 실습 서버의 Gemma4
개발 목표: 스마트폰에서 나중에 확인하고 싶은 콘텐츠를 간단하게 저장하고 다시 찾아볼 수 있는 앱 개발
2. 문제 정의 (불편했던 점)

스마트폰을 사용하다 보면 인터넷에서 나중에 읽고 싶은 글이나 유용한 정보를 자주 발견한다.

하지만 이러한 콘텐츠를 카카오톡 나에게 보내기, 브라우저 북마크, 메모장 등 여러 곳에 따로 저장하다 보면 나중에 어디에 저장했는지 기억하기 어렵다.

또한 저장한 링크가 많아질수록 원하는 콘텐츠를 다시 찾는 것도 불편하다.

해결하고 싶은 문제

나중에 읽으려고 저장한 링크를 잊어버린다.
여러 곳에 콘텐츠를 저장해서 관리하기 어렵다.
저장한 콘텐츠를 다시 찾는 데 시간이 오래 걸린다.
3. 해결 방안

'나중에 보기'라는 하나의 공간에 콘텐츠를 모아서 저장하고 관리할 수 있도록 한다.

사용자가 링크를 입력하면 Gemma4를 활용해 콘텐츠의 제목을 추천하고, 저장된 콘텐츠는 목록에서 확인할 수 있도록 만든다.

복잡한 기능은 제외하고 저장, 목록 확인, 링크 열기, 삭제 기능에 집중한다.

4. 주요 기능
기능	설명
콘텐츠 저장	링크와 제목을 입력하여 저장
AI 제목 추천	Gemma4를 이용해 입력한 링크 관련 설명이나 메모를 바탕으로 제목 추천
저장 목록	저장한 콘텐츠를 목록으로 확인
링크 열기	저장한 콘텐츠를 선택하면 원본 링크 열기
콘텐츠 삭제	더 이상 필요하지 않은 콘텐츠 삭제
5. Gemma4 활용 계획

이번 프로젝트에서는 실습 서버의 Gemma4 모델을 사용한다.

활용 목적: 저장할 콘텐츠의 제목 추천

사용자가 링크와 간단한 설명을 입력하면 Gemma4에 전달하여 콘텐츠를 쉽게 알아볼 수 있는 짧은 제목을 추천받는다.

예시:

입력 링크: 개발 관련 블로그 주소
사용자 설명: React 초보자를 위한 기초 설명
Gemma4 결과: React 초보자를 위한 기초 가이드

추천된 제목은 사용자가 확인하고 수정한 뒤 저장할 수 있도록 한다.

※ Gemma4가 웹페이지에 직접 접근할 수 있다고 가정하지 않는다. 링크와 사용자가 입력한 설명을 모델에 전달하는 방식으로 구현한다.
