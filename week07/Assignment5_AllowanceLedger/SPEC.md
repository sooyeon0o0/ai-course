# 과제 5. 용돈 기입장

## 1. 기술과 파일 구성

- Python 3.10 이상과 Flet 1.0을 사용한다.
- 외부 패키지는 Flet만 사용하고, `logic.py`에는 Flet을 import하지 않는다.
- `main.py`는 강의의 Flet 1.0 뼈대에 나온 문법만 사용한다.
- 파일은 `SPEC.md`, `logic.py`, `main.py`, `test_logic.py`로 구성한다.

## 2. 동작 규칙

- 내용, 금액, 구분을 입력해 거래를 추가한다. 구분은 `수입`과 `지출`만 허용한다.
- 내용은 앞뒤 공백을 제거한 뒤 한 글자 이상이어야 한다.
- 금액 입력의 쉼표와 앞뒤 공백은 무시하며, 0보다 큰 정수만 허용한다.
- 입력이 잘못되면 목록에 추가하지 않고 안내 문구를 표시한다.
- 거래를 추가하면 입력창을 비우고 목록과 합계를 갱신한다.
- 각 줄의 삭제 버튼을 누르면 해당 거래를 지우고 수입 합계, 지출 합계, 잔액을 다시 계산한다.
- 잔액은 `수입 합계 - 지출 합계`이다.
- 화면에 표시하는 모든 금액은 천 단위마다 쉼표를 넣고 뒤에 `원`을 붙인다.
- 추가 기능: 현재 저장된 전체 거래 건수를 함께 표시한다.

## 3. 화면

- 내용 입력창, 금액 입력창, 수입/지출 선택 목록, `추가` 버튼을 둔다.
- 수입 합계, 지출 합계, 잔액, 거래 건수를 표시한다.
- 목록의 각 줄에는 구분, 내용, 금액과 `삭제` 버튼을 둔다.

## 4. 테스트

| 입력 | 기대 결과 |
|---|---|
| `용돈`, `10000`, `수입` | 정상 거래 |
| `간식`, `2,500`, `지출` | 금액 2500인 정상 거래 |
| 빈 내용 | 입력 오류 |
| 금액 `0`, `-1`, `abc`, `1.5` | 입력 오류 |
| 잘못된 구분 | 입력 오류 |
| 수입 10,000, 지출 2,500 | 수입 10,000, 지출 2,500, 잔액 7,500 |
| 금액 1234567 | `1,234,567원` |
