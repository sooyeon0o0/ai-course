# 과제 2. 숫자 맞히기

## 1. 기술과 파일 구성

- Python 3.10 이상과 Flet 1.0을 사용한다.
- 외부 패키지는 Flet만 사용하고, `logic.py`에는 Flet을 import하지 않는다.
- `main.py`는 강의의 Flet 1.0 뼈대에 나온 문법만 사용한다.
- 파일은 `SPEC.md`, `logic.py`, `main.py`, `test_logic.py`로 구성한다.

## 2. 동작 규칙

- 새 게임을 시작하면 1부터 100 사이의 정답을 무작위로 하나 정한다.
- 입력은 앞뒤 공백을 무시하며, 정수만 허용한다.
- 빈 입력, 정수가 아닌 입력, 1~100 밖의 입력은 시도 횟수와 기록에 포함하지 않고 안내 문구를 표시한다.
- 정답보다 작은 값을 입력하면 `더 큽니다`, 큰 값을 입력하면 `더 작습니다`라고 판정한다.
- 유효한 시도마다 시도 횟수를 1 증가시키고 입력값과 판정을 목록에 추가한다.
- 정답을 맞히면 시도 횟수와 함께 성공 문구를 표시한다. 새 게임 전에는 이후 입력을 처리하지 않는다.
- 새 게임은 정답, 시도 횟수, 기록, 입력값, 안내 문구를 모두 초기화한다.
- 추가 기능: 오답을 입력할 때마다 현재 가능한 정답 범위를 좁혀서 보여 준다.

## 3. 화면

- 제목, 숫자 입력창, `확인` 버튼, `새 게임` 버튼을 둔다.
- 시도 횟수, 가능한 정답 범위, 결과/안내 문구를 표시한다.
- 아래쪽 목록에는 `입력값 - 판정` 형식으로 시도 기록을 쌓는다.

## 4. 테스트

| 입력 | 기대 결과 |
|---|---|
| `50`, 정답 `70` | `더 큽니다` |
| `90`, 정답 `70` | `더 작습니다` |
| `70`, 정답 `70` | `정답입니다` |
| 빈 문자열 | 입력 오류 |
| `abc` | 입력 오류 |
| `0`, `101` | 범위 오류 |
| 범위 1~100에서 40 입력, `더 큽니다` | 새 범위 41~100 |
| 범위 41~100에서 80 입력, `더 작습니다` | 새 범위 41~79 |
