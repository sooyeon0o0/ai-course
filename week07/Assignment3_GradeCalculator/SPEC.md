# 과제 3. 학점 계산기

## 1. 기술과 파일 구성

- Python 3.10 이상과 Flet 1.0을 사용한다.
- 외부 패키지는 Flet만 사용하고, `logic.py`에는 Flet을 import하지 않는다.
- `main.py`는 강의의 Flet 1.0 뼈대에 나온 문법만 사용한다.
- 파일은 `SPEC.md`, `logic.py`, `main.py`, `test_logic.py`로 구성한다.

## 2. 동작 규칙

- 과목 이름, 학점 수, 성적을 입력해 목록에 추가한다.
- 과목 이름은 앞뒤 공백을 제거한 뒤 한 글자 이상이어야 한다.
- 학점 수는 1, 2, 3 중에서 고른다.
- 성적과 점수는 A+ 4.5, A0 4.0, B+ 3.5, B0 3.0, C+ 2.5, C0 2.0, D+ 1.5, D0 1.0, F 0이다.
- 평점은 `(성적 점수 × 학점 수)의 합 ÷ 총 학점`으로 계산한다.
- 잘못된 입력은 추가하지 않고 안내 문구를 표시한다.
- 각 과목의 삭제 버튼을 누르면 해당 과목을 지우고 총 학점과 평점을 다시 계산한다.
- 과목이 없을 때 총 학점과 평점은 0이다.
- 평점은 소수점 아래 두 자리로 표시한다.
- 추가 기능: 현재 등록된 전체 과목 수를 표시한다.

## 3. 화면

- 과목 이름 입력창, 학점 수와 성적 선택 목록, `추가` 버튼을 둔다.
- 총 학점, 평점, 과목 수와 오류 안내를 표시한다.
- 목록의 각 줄에는 과목 이름, 학점 수, 성적과 `삭제` 버튼을 둔다.

## 4. 테스트

| 입력 | 기대 결과 |
|---|---|
| `자료구조`, 3, A+ | 정상 과목, 점수 4.5 |
| 빈 과목 이름 | 입력 오류 |
| 학점 0 또는 4 | 입력 오류 |
| 알 수 없는 성적 | 입력 오류 |
| 3학점 A+, 2학점 B0 | 총 5학점, 평점 3.9 |
| 빈 목록 | 총 0학점, 평점 0 |
