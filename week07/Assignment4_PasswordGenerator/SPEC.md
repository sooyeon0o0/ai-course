# 과제 4. 비밀번호 생성기

## 1. 기술과 파일 구성

- Python 3.10 이상과 Flet 1.0을 사용한다.
- 외부 패키지는 Flet만 사용하고, `logic.py`에는 Flet을 import하지 않는다.
- `main.py`는 강의의 Flet 1.0 뼈대에 나온 문법만 사용한다.
- 파일은 `SPEC.md`, `logic.py`, `main.py`, `test_logic.py`로 구성한다.

## 2. 동작 규칙

- 소문자는 항상 포함한다.
- 대문자, 숫자, 특수문자(`!@#$%^&*`)는 체크 상자로 선택한다.
- 길이는 앞뒤 공백을 무시한 정수여야 하며 4 이상 32 이하여야 한다.
- 길이가 잘못되면 비밀번호를 만들지 않고 결과를 비운 뒤 안내 문구를 표시한다.
- 선택한 각 문자 종류는 결과에 적어도 한 글자씩 포함한다.
- 나머지 글자는 선택된 전체 문자 모음에서 무작위로 고르고, 전체 순서도 무작위로 섞는다.
- 추가 기능: 길이와 문자 종류 수를 바탕으로 `보통`, `강함`, `매우 강함`의 강도 안내를 표시한다.

## 3. 화면

- 길이 입력창과 대문자, 숫자, 특수문자 체크 상자를 둔다.
- `비밀번호 만들기` 버튼 아래에 생성 결과, 강도, 오류 안내를 표시한다.

## 4. 테스트

| 입력 | 기대 결과 |
|---|---|
| 길이 `4`, 선택 없음 | 길이 4, 소문자만 포함 |
| 길이 `12`, 모두 선택 | 각 종류가 한 글자 이상 포함 |
| 길이 `3`, `33` | 범위 오류 |
| 빈 문자열, `abc` | 입력 오류 |
| 길이 12, 네 종류 | 강도 `강함` |
| 길이 16, 네 종류 | 강도 `매우 강함` |
