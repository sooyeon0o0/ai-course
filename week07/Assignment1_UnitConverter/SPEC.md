# 과제 1. 단위 변환기

## 1. 기술과 파일 구성

- Python 3.10 이상과 Flet 1.0을 사용한다.
- 외부 패키지는 Flet만 사용하고, `logic.py`에는 Flet을 import하지 않는다.
- `main.py`는 강의의 Flet 1.0 뼈대에 나온 문법만 사용한다.
- 파일은 `SPEC.md`, `logic.py`, `main.py`, `test_logic.py`로 구성한다.

## 2. 동작 규칙

- 변환 가능한 단위는 길이 `mm`, `cm`, `m`, `km`와 온도 `°C`, `°F`이다.
- 출발 단위와 도착 단위 목록에는 여섯 단위가 모두 들어간다.
- 입력값은 앞뒤 공백을 무시하며 정수와 소수를 허용한다.
- 빈 입력이나 숫자가 아닌 입력은 결과를 비우고 안내 문구를 표시한다.
- 길이와 온도를 섞어 선택하면 변환하지 않고 안내 문구를 표시한다.
- 같은 단위를 고르면 입력값과 같은 값을 결과로 표시한다.
- 길이는 미터를 기준으로 변환하며, 온도는 섭씨와 화씨 공식으로 변환한다.
- 결과는 소수점 아래 최대 6자리까지 표시하고 불필요한 0은 제거한다.
- 추가 기능: 정상 변환 결과를 기록 목록에 쌓고 각 기록을 삭제할 수 있다.

## 3. 화면

- 값 입력창, 출발 단위 목록, 도착 단위 목록, `변환` 버튼을 둔다.
- 결과와 오류 안내를 표시하고, 아래에 변환 기록 목록을 둔다.
- 각 기록에는 `삭제` 버튼을 둔다.

## 4. 테스트

| 입력 | 기대 결과 |
|---|---|
| `10 cm → mm` | `100` |
| `1000 m → km` | `1` |
| `1 km → m` | `1000` |
| `0 °C → °F` | `32` |
| `212 °F → °C` | `100` |
| 길이 → 온도 | 종류 오류 |
| 빈 문자열, `abc` | 입력 오류 |
